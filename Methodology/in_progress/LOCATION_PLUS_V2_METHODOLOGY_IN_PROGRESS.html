1. Architecture — Decomposed Classifier Design

Location+ v2 replaces v1's single regression model with a five-classifier decomposed architecture that mirrors how pitching outcomes actually branch:

  1. xSwing% — Will the batter swing?
  2. xCS% — Given no swing, is it a called strike?
  3. xWhiff% — Given a swing, does the batter miss?
  4. xFoul% — Given a swing and contact, is it a foul?
  5. BIP type × EV distribution — Given a batted ball, what type at what exit velocity? (20-class multiclass)

Each classifier outputs a probability. These combine via a fixed run-value table (training/v2_artifacts/run_value_table.json) to produce a per-pitch expected run value (xRV). xRV is aggregated across pitcher-seasons, then converted to the plus-scale.

The run-value table is fixed and shared across all four decomposed models (Location+ v2, Tunneling+ v2, Stuff+ decomposed v1). No rebuilding needed at scoring time.

3. Classifier Performance (LOSO CV, 2015–2025)

AUC guide: 0.50 = coin flip (useless). 0.70 = useful. 0.80 = strong. 0.90 = very strong. The xCS% AUC is very high because the strike zone is a nearly deterministic function of plate location — exactly what this model's features directly capture.
