# Root Files

Every file at the project root with its justification.

| File | Justification |
|---|---|
| `mlb_data.db` | Primary SQLite database; read by all API routes via `api/db.py` |
| `requirements.txt` | Python dependency list; read by pip/venv setup |
| `schema.sql` | Database DDL; reference for `CREATE TABLE` statements; used when re-creating DB from scratch |
| `start.sh` | Launch script (`uvicorn api.main:app --port 8010`); the documented way to start the server |
| `ARCHITECTURE.md` | Architecture overview; referenced in onboarding and the audit |
| `HOSTING.md` | Deployment / hosting notes for production environments |
| `PROMOTION_CHECKLIST.md` | Pre-promotion checklist; used when promoting a model or feature to production |
| `PROMOTION_LOG.md` | Promotion history log; records when each model version was promoted |
| `.gitignore` | Git configuration; controls what is tracked |
| `.gitattributes` | Git LFS and diff attributes for binary files |
| `CTempserver_8012.log` | **Candidate for Archive/**: temporary server log file generated by the dev server; no functional purpose. Move to `Archive/` or delete if confirmed not needed. |
