How to read this number
100 = league average for that season. Each 10 points is one standard deviation. Scores are z-scored fresh within each season, so the same score in two different years means the same relative standing. Location+ needs ~300 pitches before it is reliable at the pitcher level (split-half r ≥ 0.81 at 300+ pitches per half) — read leaderboard positions below that pitch count with real caution.
