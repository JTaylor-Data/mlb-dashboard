Stuff+ Model

v2: one gradient-boosted (LightGBM) model across every pitch type, trained on delta_run_exp (linear-weights run value per pitch, not just batted balls) using only the pitch's own physical characteristics - velo, movement, spin, release point, and an approach-angle residual with plate height's effect subtracted out. No location, count, or pitcher identity is fed in - see the model report below for exactly what is. Replaces v1 (separate plain-OLS regression per pitch type, no cross-validation).

Small-Sample Shrinkage

A pitcher's raw sample mean gets pulled toward the pitch type's league average when the sample is small - less so for a type where pitch-to-pitch variation is naturally tiny (a small K below), more so where it isn't. Reliability at n pitches = n / (n + K).
