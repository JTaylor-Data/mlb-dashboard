Stuff+ Model

One gradient-boosted (LightGBM) model across every pitch type, trained on delta_run_exp (linear-weights run value per pitch, not just batted balls) using only the pitch's own physical characteristics - velo, movement, spin, an approach-angle residual with plate height's effect subtracted out, how a pitch's velo/movement separates from the pitcher's own primary fastball, and an empirically-calibrated seam-shifted-wake proxy (axis differential). No location, count, or pitcher identity is fed in - see the model report below for exactly what is. Full methodology and architecture history: Methodology/STUFF_V3_REPORT.md.

ℹ️
How to read this number
100 = league average for that season. Each 10 points is one standard deviation from that season's league-wide average - a score of 120 means a pitch graded roughly 2 standard deviations better than average that season, not "20% better." That percentage-style reading is a common mistake (closer to how a stat like wRC+ happens to work, but Stuff+ isn't scaled that way). Scores are also z-scored fresh within each season, so the same score in two different years means the same relative standing, not necessarily the same underlying raw value.

Small-Sample Shrinkage

A pitcher's raw sample mean gets pulled toward the pitch type's league average when the sample is small - less so for a type where pitch-to-pitch variation is naturally tiny (a small K below), more so where it isn't. Reliability at n pitches = n / (n + K).
