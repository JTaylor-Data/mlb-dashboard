## Repository Layout

```
mlb_dashboard/
├── api/                    # FastAPI application
│   ├── main.py             # App factory, middleware, router registration, admin endpoints
│   ├── cache.py            # TTL cache (ttl_cache, ttl_cache_all_args) + global registry
│   ├── db.py               # SQLite helpers (get_db, query helpers)
│   ├── pull.py             # Statcast / team-stat pull logic; POSTSEASON_MODE derived here
│   ├── scheduler.py        # APScheduler jobs (nightly pulls, cache warm)
│   ├── warmup.py           # Server startup cache warm-up
│   ├── presentation.py     # Shared formatting helpers for API responses
│   └── routers/            # One file per feature area (see below)
│
├── analytics/              # Business logic — model scoring, features, stats
│   ├── stuff_model.py      # Stuff+ v4 scorer (ACTIVE)
│   ├── location_v3_model.py # Location+ v3 scorer (ACTIVE)
│   ├── tunneling_v2_model.py # Tunneling+ live scorer — OUT OF SCOPE for audit
│   ├── deception_model.py  # Deception+ v2b scorer (ACTIVE, scores currently empty)
│   ├── percentile_cache.py # In-memory percentile lookup (populated at startup)
│   ├── percentiles.py      # Percentile calculation helpers
│   ├── player_page.py      # Player page data assembly
│   ├── standings.py        # Standings logic
│   ├── splits.py           # Pitch-type splits
│   ├── metrics.py          # Shared rate-stat helpers
│   └── ...                 # Other feature/stat modules
│
├── config/                 # Single-source constants (import from here, not inline)
│   ├── model_policy.py     # CURRENT_SEASON=2026, active model versions, thresholds
│   ├── season_phase.py     # SEASON_PHASE constant + helpers (is_postseason, etc.)
│   └── qualifiers.py       # Per-model min-pitch thresholds, usage filter, pitch-type map
│
├── frontend/               # Static HTML/JS/CSS served by FastAPI StaticFiles
│
├── models/                 # LightGBM .txt boosters (binary, gitattributes marks as LFS)
│
├── scores/                 # Pre-computed score parquets (gitignored, generated by rescore)
│
├── data/                   # Reference CSVs (rosters, park factors, schedule, etc.)
│
├── diagnostics/            # ONLY diagnostics/stuff_v4/ remains here (read by build tools)

├── tools/                  # Build / content-generation utilities
│   └── build_validation_content.py  # Reads diagnostics/stuff_v4/ to build validation page

├── tests/                  # pytest suite

│   ├── test_imports.py             # Import-everything check
│   └── test_cache_keys.py          # Cache key isolation tests
│
├── Methodology/            # Audit docs, decisions, benchmarks, golden snapshots
│   ├── AUDIT_REPORT.md     # Defects, redundancies, perf items, dead code
│   ├── LIVE_MANIFEST.md    # ~55 live Python modules documented
│   ├── SEASON_PHASE.md     # Phase transition guide
│   └── golden_snapshots/stage0/   # JSON baselines captured before audit changes
│
├── Archive/                # Non-live code preserved for reference (never imported by server)
│   ├── training_scripts/   # Offline model training runs
│   ├── diagnostics/        # Model development diagnostic outputs
│   ├── experimental/       # pitcher_cv (video delivery-timing R&D)
│   ├── misc_scripts/       # Utility scripts (rescore_models.py)
│   └── artifacts/          # Old model artifacts from pitching_plus_ext training
│
├── pulls/                  # Downloaded Statcast parquets (gitignored)

├── perf/                   # Perf benchmark outputs
```

## Active Models

| Model | Version | Scorer module | Score parquet | Min pitches |
|-------|---------|---------------|--------------|-------------|
| Stuff+ | v4 | `analytics/stuff_model.py` | `scores/stuff_v4_scores.parquet` | 200 (leaderboard) |
| Location+ | v3 | `analytics/location_v3_model.py` | `scores/location_v3_scores.parquet` | 300 (scoring) |
| Tunneling+ | v2 (live as v3 in routes) | `analytics/tunneling_v2_model.py` | `scores/tunneling_scores.parquet` | 100 |
| Deception+ | v2b | `analytics/deception_model.py` | `scores/deception_v2b_scores.parquet` | None |

Active versions are governed by `config/model_policy.py` (DECEPTION_ACTIVE_VERSION, CURRENT_SEASON, etc.).

## Data Flow

```
Statcast pull (api/pull.py + scheduler)
        |
        v
pulls/*.parquet  <-->  SQLite (api/db.py)
        |
        v
analytics/*_model.py  (score computation)
        |
        v
scores/*.parquet  (pre-computed, gitignored)
        |
        v
api/routers/*.py  (load scores + db, build JSON responses)
        |
        v
FastAPI (api/main.py)  --TTL cache (api/cache.py)-->  HTTP JSON
        |
        v
frontend/*.html/js  (static, served as StaticFiles)
```

## Caching

`api/cache.py` provides:
- `@ttl_cache()` — caches on first positional arg (season), 12h TTL
- `@ttl_cache_all_args()` — caches on all args, 12h TTL
- `cache._registry` — all registered cache functions
- `POST /api/admin/refresh-cache` — clears all registered caches
- `GET /api/admin/cache-stats` — live/expired entry counts per function

`lru_cache` (no TTL) is used ONLY in Tunneling+ (out of scope).

## Season Phase

`config/season_phase.py` is the single source for `SEASON_PHASE`. Set via env var:

```bash
SEASON_PHASE=REGULAR_SEASON  # or POSTSEASON or OFFSEASON
```

Defaults to `POSTSEASON` when unset. `api/pull.py` derives `POSTSEASON_MODE` from this.
See `Methodology/SEASON_PHASE.md` for the full transition checklist.

## Validation

- `tools/build_validation_content.py` reads `diagnostics/stuff_v4/` to produce the validation page.
- `tests/golden_snapshots/stage0/` holds JSON baselines from before the audit.
- Run `pytest tests/ -q` with the server live on port 8010 to check all smoke + snapshot tests.
