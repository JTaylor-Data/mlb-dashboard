What It Measures

Tunneling+ measures how indistinguishable a pitcher's pitch types are from each other out of the hand, and how much they separate late near the plate. The core intuition: a fastball and a changeup that look identical at the decision point (roughly 167 ms before the plate) then separate sharply by contact force a worse swing decision.

The model estimates xRV (expected run value per pitch) from the sequence context of each pitch — specifically, how the preceding pitch's geometry (distance at commitment point and at plate, and shape divergence) should influence the pitch outcome. Aggregated across a season and plus-scaled, higher scores mean harder pitchers to track.

Why v2? The previous live model (tunneling_v3.txt, single regressor trained on derived tunneling geometry stats) had a sign-flip: ERA r = −0.218, xFIP r = −0.348, meaning higher scores predicted worse pitchers. v2 fixes this: ERA r = +0.182, xFIP r = +0.337. The decomposed 5-classifier xRV architecture naturally produces correctly-signed scores by grounding predictions in real pitch outcome probabilities.

Each classifier is a LGBMClassifier(n_estimators=500, num_leaves=31, learning_rate=0.05, min_child_samples=50, subsample=0.8, colsample_bytree=0.8) trained with leave-one-season-out cross-validation on 2021–2025 (classifier selection) and then fit on the full 2015–2026 corpus (live inference).

Combine Formula

Per-pitch xRV is computed as:

xRV = p_sw × (p_wh × rv_whiff + (1−p_wh) × (p_fo × rv_foul + (1−p_fo) × (p_bip · bip_rvs))) + (1−p_sw) × (p_cs × rv_cs + hbp_rate × rv_hbp + clip(1−p_cs−hbp_rate,0,1) × rv_ball)

where run values come from a fixed 2021–2025 league-average table, not re-estimated per pitcher. HBP rate = 0.51% (league average).

Features

28 features total across all five classifiers (same feature matrix for all classifiers):

GroupFeaturesCount
Geometry lagslagN_commit_distance, lagN_plate_distance, lagN_shape_break for N=1–618
Pitch-type lagslagN_pitch_type for N=1–6 (categorical)6
Current pitchpitch_type, p_throws, stand, season (all categorical)4

Lag slots are filled at the "commit point" (200 ms from contact, ≈ 23.5 ft from plate) — only pitches after a qualifying prior pitch in the same game by the same pitcher. Commit point determined per pitcher-season by the 5th-percentile decision reaction time.

Exclusions by design: no plate location (that's Location+), no count (Location+ handles this), no pitcher identity (generalises across pitchers).

Diagnostic Studies

Part A — Corrected Sequential Same-At-Bat Test (2026-09-21)

The original Part 4 sequential test bucketed pitches by full blended xRV, which embeds the model's own xWhiff% prediction — a near-circular test (z = 180.1). The corrected test isolates SHAP contributions by feature group on a 200K-row sample.

SHAP Groupz (high tercile − low)Assessment
Lag-1 geometry (commit/plate/shape)−1.706NULL — geometry not independently predictive of real whiff
All-lag geometry (6 slots × 3 features)+1.635NULL — extending to all lags recovers nothing
Pitch-type lag (lag1–6 pitch_type)+18.622REAL SIGNAL — sequencing is genuine

Finding: xWhiff% model's signal comes from pitch-type sequencing, not geometric measurement. Tunneling+ v2 stays live — the ERA/xFIP sign-flip fix remains valid regardless.

Part A2 — Full 5-Classifier Geometry Isolation (2026-09-21)

Extended the corrected isolation to all five classifiers (200K sample each, 30K for BIP). Confirms that geometry carries different signal per classifier.

Geometry predicts pitch-selection decisions (swing/take) strongly and BIP probability weakly. It is null for whiff and inverts for foul. Contact quality (exit velo) is uncorrelated with geometry (t≈1.4). The model captures whether hitters are fooled into a wrong decision, not what happens when they make contact.

v2.1 Candidate — Targeted xFoul% Fix (R&D)

Status: Candidate only. Tunneling+ v2 stays live regardless of this study's outcome. Not wired into api/.

General rule applied: Drop lagN_{commit_distance, plate_distance, shape_break} from any classifier where those features show a statistically significant wrong-signed effect on that classifier's own real target outcome. Keep geometry where null or correctly signed. xFoul% is the only current trigger (Part A2: lag1 z=−21.8, alllag z=−44.6).

Known Issues

  • xFoul% geometry inversion: documented above; v2.1 candidate under R&D. v2 stays live.
  • xCS% pitch-type confound: ~0.028 of the 0.742 AUC comes from pitch-type columns. Ablation: removing all pitch-type drops AUC to 0.713. 96% of signal is genuine. Artifact: training/v2_artifacts/tunneling_plus_v2_xcs_ablated_meta.json.
  • No SHAP breakdown in live API: decomposed-classifier architecture has no single SHAP model to query. API returns shap_note; frontend displays the note gracefully (pending fix).
  • Pitch Locations chart orientation: may show RHH/LHH backwards vs. Baseball Savant. Deferred.
